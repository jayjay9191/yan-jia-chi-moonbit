# 验价尺 · MoonBit 版

量一量 AI 工具的真实定价。

一眼看到它在算什么（真实命令输出，2026-11-18 当场跑出，与当前代码逐字节一致）：

```sh
$ moon run cmd/main normalize '$8/月按年'
$8/月按年 → 月均价：USD 8.00/月
  （按年付折算）

$ moon run cmd/main normalize '$49/年'
$49/年 → 月均价：USD 4.08/月
  （按年付折算）

$ moon run cmd/main normalize '定制定价'
定制定价 → 无法归一化：定制定价：无固定金额
```

归一化不是查表：单档价折算成可比月均价（分取整），年付省多少由 MoonBit 算出来；算不了的明确拒绝、不猜数。对照表见“价格归一化”一节。

## 价格归一化（月均价折算，MoonBit 核心语义处理）

`normalize.mbt`：把不同写法的单档价格折算成可比的月均价（分取整），
核价结论由 MoonBit 算出来，不是 Python——Python 只负责把 JSON 原样搬进
`pricing_data.mbt`（生成器），14 项校验、状态判定、过期判定与归一化
都在 MoonBit 里。

- 能算的：`$8/月按年` → USD 8.00/月；`$96/年` → USD 8.00/月（年总价 / 12）；
  `¥990/年`（走工具记录的 currency 字段）→ CNY 82.50/月；`$8.33/月` → 833 分；
  按席计价（`$69/席/月`）单独标记“每席每月”；同档位按月价与按年折算月费率
  之差算年付节省率（Midjourney 四档均为 20%，见下）。
- 明确拒绝、不猜数：多档合写（`；`/`、`/`or` 分隔）先指定档位；按量（`/1M tokens`）、
  定制（`联系销售`）、免费档与付费价混写、无货币符号、无计费周期，一律拒绝
  并说明原因；`¥` 裸符号无法区分人民币与日元时也拒绝，须走工具记录的
  currency 字段；NT$/HK$/R$ 不认作美元，记 Other。不同货币之间不比较、不换算。

跨天对照：Oura（APV-0344）2026-11-15 首次核验，11-15（R3）与 11-16（R4）
两天各复核一次，均无变化。MoonBit 对四档逐档
折算：Basic $10/月按月 vs $8/月按年 → 月均 $10.00 vs $8.00，省 20%；
Standard $30 vs $24、Pro $60 vs $48、Mega $120 vs $96，均为 20%。
结论“已核验、无变化”由复核记录 + 归一化计算共同给出。

## 分工：人工 / Python / MoonBit

| 步骤 | 人工 | Python | MoonBit |
| --- | --- | --- | --- |
| 采集 | 打开官网逐页读价、挑工具、记页面可达性。 | 一次性 CSV 导入与批次 JSON 合并，分配唯一记录键与核验会话。 | 不参与：CLI 不联网、不打开官网。 |
| 清洗 | 按流程标空白/部分核验、判歧义（如 Tana 价疑似年付先留白、Bettermode 二手转述降级）。 | 合并时用 Python 镜像 14 项规则预检，有问题不写盘。 | 14 项校验规则 `verify` 当场卡住假数据（如涨价/降价须新旧价俱全且不同）。 |
| 归一化 | 核验时按官网实测写死每条记录的 currency 字段。 | 只把 JSON 原样搬进 `pricing_data.mbt`，不算价格。 | `normalize.mbt` 折算月均价（分取整）与年付节省率，算不了的明确拒绝。 |
| 判定 | 定口径、判升级/降级（如 DeepInfra 复核确认后升已核验）。 | 不判状态、不下结论。 | 三档状态判定、30 天过期判定、5 步证据链输出。 |
| 复核 | 重开官网逐条比对，变动记进 history（只允许 6 种）。 | `merge_batches.py` 的 apply_recheck* 幂等应用复核结论，按会话去重。 | `stale` 标出超期记录，`report` 汇总轨迹与分母。 |

分工与 `docs/verification-process.md` 的实际流程一致。例：Tana Pro $15 在复核时未注明计费周期、疑似年付价，人工先记“未看到价”留白；两组独立核验一致后才记降价，歧义保留在 note 里，不猜。

## 数据说明

- 唯一事实源是 `data/pricing.json`，改数据只改 JSON，改完跑
  `python3 scripts/generate_data.py`（再跑 `moon fmt && moon test`）。
- 逐工具断言由 `python3 scripts/generate_tests.py` 从 JSON 生成，
  JSON 一变测试跟着变。
- CSV 导入是一次性的：`python3 scripts/csv_to_json.py`（源 CSV 在
  `data/seed-pricing-2026-11-08.csv`，即那 20 条种子数据，已随仓库提交）。
  注意源 CSV 有个小毛病——ChatGPT、Gemini 两行的千分位价格（JP¥1,400、
  JP¥1,450）没加引号，直接用 csv 模块会切错字段；导入脚本按首尾字段
  定位 + 计费周期查表重组，并对 reachable、计费周期做交叉校验。
- 价格只在核验当天有效，官网随时会改；本工具的政策是
  30 天复核一次，`stale` 会标出过期记录。复核结果记进每条记录的
  `history`（变动类型只允许 6 种：无变化/涨价/降价/下架/新档位/
  未看到价），没有第二次实测就没有变动记录。
- 每条记录有唯一记录键 `key`（APV-0001 起按 JSON 顺序分配，追加不重排）
  与核验会话 `session`（如 20261108-LXM、20261115-A～F、复核 20261115-R1），
  `check` 输出 5 步证据链，任何人能按图索骥重走一遍。核验流程详见
  `docs/verification-process.md`。
