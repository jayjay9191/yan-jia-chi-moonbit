# 核验流程（verification process）

本文件只写真实做过的步骤，对标 J006 的 7 页过程文档。
数据：2026-11-15，410 条（原始 20 条 + 扩量 390 条）。

## 1. 怎么挑工具

- 种子：用户 Lexmount 第二份作品的 20 条记录（2026-11-08，云端浏览器
  实际打开各官网逐页核验），见 `data/seed-pricing-2026-11-08.csv`。
- 扩量：十三批、每批 30 个，按类别分——
  A 写作/文案/语法、B 图像/设计、C 视频/音频/语音、D 编程/开发、
  E LLM API/云基础设施、F 办公生产力/AI 搜索/其他、
  G 客服/聊天机器人、H 营销/SEO/广告、I 数据分析/BI、J 教育/学习、
  K 健康/医疗、L 金融/财务、M 人力资源/招聘。
  先补种子里“未核验到”的同类工具（Notion AI、Jasper、Runway、Suno、
  Groq、OpenRouter 等），再往外扩到公认的 AI 工具。
- 只挑有公开定价页的工具。没有公开定价页的工具不在这批里，
  不硬凑。

## 2. 怎么开官网、怎么读价

- 每条记录的 `pricing_url` 就是当时打开的官方定价页地址，
  不是搜索结果页、不是第三方汇总页。
- 打开方式：云端浏览器直接打开官方定价页，读页面文本里的档位价；
  打不开时可用官方域名返回的定价片段（记来源 URL）。读到的价按原文
  记进 `paid_price`（含档位名、金额、计费周期），货币记 `currency`
  （USD/JPY/CNY），计费周期记 `billing`。
- 免费版记 `free_tier`（如 Free $0、免费 15GB）；学生/教育优惠记
  `student_discount`——页面上没看到就写“未见”，“未见”指页面上没看到，
  不是“没有优惠”。
- 页面可达性记 `reachable`：能打开 / 打不开 / 受限（地区限制、登录墙、
  抓取策略拦截都算“受限”或“打不开”，并在 `note` 里写清原因）。

## 3. 找不到价怎么办（标空白，不编造）

- 官方页上找不到价的，状态标“未核验到”，`paid_price`、`currency`、
  `billing` 全部留空，绝不编造。
- 只核验到一部分的（如只见到起步价、只核验到商业版、实时页无价但
  有存档快照价），标“部分核验”，把已核验到的价记下来，并在 `note`
  里写清“只核验到什么、没核验到什么”。
- 第三方汇总文章的价格一律不采纳，哪怕多家一致。实例：
  - Leonardo.Ai：档位表可见，但价格卡片 JS 渲染、文本抓取无 $ 金额；
    第三方一致转述 Essential $12、Premium $30、Ultimate $60/月，未采信。
  - Kling AI：会员页只抓到标题，价格未见；第三方转述未采纳。
  - Suno：suno.com 域名被抓取策略拦截，无法直接打开定价页；
    第三方一致转述 Free $0、Pro $10/月、Premier $30/月，未采纳。
  - Tabnine：官方定价页已跳转至 Tricentis 联系页，实时页无价格；
    $39/$59 只来自 2026-09-05 官网存档快照，降级为部分核验并写清来源。
- 欧元/英镑定价的工具：本批没有欧元/英镑专属定价的已核验记录；
  如遇只显示 €/£ 的页面，按“未核验到”处理（货币只认 USD/JPY/CNY）。
- 全免费、无付费档的工具：标“未核验到”，`note` 写“无付费定价，全免费”。

## 4. 怎么合进总表（合并流程）

- 每批一个 JSON 文件（`/tmp/batch_A.json`～`/tmp/batch_F.json`），
  字段与 `data/pricing.json` 一致。交文件前，核验员先做 7 条硬规则自查
  （状态三档、价格与状态双向一致、货币符号、URL 以 https:// 开头、
  日期格式、reachable 三档、免费版/学生优惠非空），0 违规才交。
- 合并用 `python3 scripts/merge_batches.py`（可加 `--only <批次字母>`
  逐批合并）。合并时：
  1. 给每条记录分配唯一记录键 `key`（APV-0001 起按 JSON 顺序，追加不重排）
     与核验会话 `session`（原始批 20261108-LXM，扩量批 20261115-A～F）；
  2. 应用已确认的修正（如 Tabnine 降级、v0 备注改引官方文档页）；
  3. 写盘前用 Python 镜像一遍 MoonBit 的 14 项验证规则，有问题不写盘。
- 合并后跑：`python3 scripts/generate_data.py`（生成数据模块）、
  `python3 scripts/generate_tests.py`（逐工具生成断言，有多少条就是多少条测试）、
  `moon fmt`、`moon test`、Python 测试、`moon run cmd/main verify`、
  `moon run cmd/main report`——全部通过才提交。六批各一个 commit（A～F）。

## 5. 怎么复核（生命周期追踪）

- 政策：价格只在核验当天有效，30 天复核一次；`stale` 命令标出超 30 天
  未复核的记录，下次复核不晚于 2026-12-08（最早核验日 2026-11-08 + 30 天）。
- 第一次复核（2026-11-15，会话 20261115-R1）：复核原始 20 条中带价的
  11 条，逐个重开官方页。结果——
  - 6 条确认无变动：DeepSeek、Claude、Grok、Midjourney、Cursor、
    Copilot（Copilot 的 $18 附加价今日页未见，但两档商业版价确认一致，
    仍记“无变化”并附注；verified_at 不动）——确认无变动的，
    verified_at 更新到复核日 2026-11-15；
  - 1 条真实涨价：智谱 GLM-5.1，输入 ¥3.5→¥6（<32K）/¥8（≥32K）、
    输出 ¥12.5→¥24/¥28；GLM-5.3 不变；GLM-5.1-Flash 在今日价目表已无此名，
    同价 ¥0.8/¥2.8 现为 GLM-5.3-Flash——`paid_price` 更新为今日价，
    history 记“涨价”并写新旧价；
  - 4 条未看到价：Kimi、ChatGPT、Gemini、海螺——原价与 verified_at
    都不动，只记“未看到价”轨迹并写清原因（JS 渲染、页面无价目表等）。
- 复核结论写死在 `scripts/merge_batches.py` 的 REVERIFY 表里，可审计；
  重复跑脚本不会重复追加（按会话去重）。
- 第二次复核（2026-11-15，会话 20261115-R2）：复核 R1 未覆盖的 121 条
  已核验/部分核验记录（94 条已核验 + 27 条部分核验），4 个复核组并行、
  逐个重开官方页比对。结果——
  - 84 条确认无变动：verified_at 更新到 2026-11-15；
  - 2 条真实降价：Intercom Fin（Essential 年付 $29→$19，页面划线价与
    记录年付价一致）、Craft（Plus 年付口径 $8/月→$4.8/月、Family $15/月
    →$9.0/月）——`paid_price` 更新为今日价，history 记“降价”并写新旧价；
  - 1 条下架：Cline（ClinePass $9.99/月订阅档已不在官方定价页，页面两次
    明写 no subscriptions）——`paid_price` 保留为历史记录、status 维持
    部分核验，history 记“下架”；
  - 34 条未看到价：页面打不开（429 限流为主，按指令未重试）、JS 渲染无价、
    页面无价目表——原价与 verified_at 都不动，只记“未看到价”轨迹。
  - 2 条升级：DeepInfra、Salesforce Einstein——复核确认记录价与官网完整
    价目表逐字一致，原先“部分核验”的原因已不存在，status 改为已核验，
    价格本身不变。Baseten 未升级：页面新增价目在 note 里语义不完整，
    无法逐字写进付费价，维持部分核验。
- 复核结论写在 `/tmp/recheck_R2_part{1..4}_result.json`，由
  `scripts/merge_batches.py` 的 `apply_recheck2` 应用（幂等、按会话去重），
  跑 `python3 scripts/merge_batches.py --recheck2-only`。
- `history` 只允许 6 种变动：无变化/涨价/降价/下架/新档位/未看到价。
  涨价/降价必须新旧价俱全且不同（验证规则第 13 条当场卡住假轨迹）。
  没有第二次实测，就没有变动记录——绝不凭空编一条。

## 6. 怎么抽查（质量把关）

- 合并后，负责人亲自打开抽查记录的官方页复核。本轮抽查 8 条：
  - 6 条已核验的价格与官网逐字对上：Grammarly（Pro $12/月）、
    Jasper（Pro $69/席/月按月、$59 按年）、Runway（Standard $15、
    Pro $35、Max $95/月）、Ideogram（Plus $20、Pro $60、Team $30/用户/月）、
    Groq（GPT OSS 120B 输入 $0.15、输出 $0.60/1M tokens）、
    Genspark（Plus $19.99/月年付、Pro $199.99/月年付）；
  - 2 条“未核验到”的空白属实：Notion AI（定价页 JS 渲染、无档位价）、
    Leonardo.Ai（价格卡片 JS 渲染、无 $ 金额）；
  - Suno 的官方页抓取被策略拦截（核验员和负责人都打不开），记录保持
    “未核验到”，备注写清原因。
